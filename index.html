Acerca de este proyecto

Red de sensores PurpleAir instalada en escuelas y jardines de infantes de Saladillo, que mide material particulado (PM2.5/PM10) en tiempo real como parte de una iniciativa de monitoreo y educación ambiental.

Arquitectura: un script en Python consulta la API de PurpleAir cada 15 minutos (GitHub Actions) y guarda los datos en Cloudflare D1; un Worker expone una API REST propia que consume este dashboard, publicado en Cloudflare Pages. Es uno de tres proyectos ambientales hermanos: emas.lemeit.ar (meteorología), este (calidad del aire) y wq.lemeit.ar (calidad del agua, en desarrollo).

Ing. Luciano Lamaita — docente de Física y Química en Saladillo, Buenos Aires — más proyectos en profe.lemeit.ar
