Acerca de este proyecto

Red de sensores PurpleAir y AirGradient instalada en escuelas, jardines de infantes y domicilios de Saladillo, que mide material particulado (PM2.5/PM10), CO2 y otros parámetros en tiempo real como parte de una iniciativa de monitoreo y educación ambiental.

Arquitectura: varios disparadores automáticos (un Worker de Cloudflare y GitHub Actions, con un respaldo externo) consultan la API de PurpleAir cada 15 minutos y guardan los datos en Cloudflare D1; un Worker expone una API REST propia que consume este dashboard, publicado en Cloudflare Pages. Es uno de tres proyectos ambientales hermanos: emas.lemeit.ar (meteorología), este (calidad del aire) y wq.lemeit.ar (calidad del agua).

Ing. Luciano Lamaita — docente de Física y Química en Saladillo, Buenos Aires — más proyectos en profe.lemeit.ar
