API · Aire Saladillo

← Volver al portal

Esta es la API pública de solo lectura que ya usa aq.lemeit.ar para mostrar los datos de la red de sensores de calidad del aire (PurpleAir y AirGradient) en escuelas y jardines de Saladillo. Cualquiera puede consumirla directamente, sin registro ni token: es de lectura, CORS abierto, y devuelve los mismos datos ambientales que ya son públicos en el portal.

Base URL: https://purpleair-saladillo-api.fisicai-eureka-01.workers.dev

GET /api/sensores

GET/api/sensores

Metadata de todos los sensores activos: nombre, institución, latitud/longitud, proveedor (purpleair / airgradient).

curl "https://purpleair-saladillo-api.fisicai-eureka-01.workers.dev/api/sensores"

GET /api/ultimas

GET/api/ultimas

Última lectura registrada de cada sensor, con su metadata.

curl "https://purpleair-saladillo-api.fisicai-eureka-01.workers.dev/api/ultimas"

GET /api/historico/:sensor_index

GET/api/historico/:sensor_index

Serie histórica de lecturas de un sensor puntual (el sensor_index se obtiene de /api/sensores o /api/ultimas).

ParámetroDescripción
rangeVentana relativa: 24h (default), 7d o 30d. Se ignora si se manda desde y/o hasta.
desdeFecha/hora UTC de inicio, formato YYYY-MM-DD o YYYY-MM-DD HH:MM:SS. Rango absoluto en vez de relativo a "ahora".
hastaFecha/hora UTC de fin, mismo formato que desde.
limitTope de filas devueltas. Default 3000, máximo 20000.
formatocsv para descargar un archivo CSV en vez de JSON (ver más abajo).
curl "https://purpleair-saladillo-api.fisicai-eureka-01.workers.dev/api/historico/12345?range=7d"

curl "https://purpleair-saladillo-api.fisicai-eureka-01.workers.dev/api/historico/12345?desde=2026-08-01&hasta=2026-08-15"

Descargar como CSV

Los tres endpoints aceptan &formato=csv y devuelven el mismo contenido en CSV, con encabezado, listo para abrir en Excel o Google Sheets:

curl -O -J "https://purpleair-saladillo-api.fisicai-eureka-01.workers.dev/api/historico/12345?range=30d&formato=csv"

Notas

No hace falta API key ni registro: los datos son de carácter ambiental y ya son públicos en el portal. La API tiene un uso moderado de todos modos — evitá consultas en loop muy frecuentes. Los timestamps se guardan y devuelven en UTC. Si vas a reutilizar estos datos públicamente, agradecemos que menciones como fuente a aq.lemeit.ar — Red de sensores de calidad del aire de Saladillo.
